# clear-sound 交互与业务逻辑设计(DESIGN)

> 本文用 ASCII 图描述界面交互、业务流程与数据流。技术选型与里程碑见 `docs/PLAN.md`。
> 设计原则:界面交互合理、文字描述清晰、大文件流畅。

## 3. 主窗 · 阅读器(核心界面)

```
┌ 主窗 · 阅读器 ──────────────────────────────────────────────────────┐
│ [☰ 目录] 书名A · 第3章 风起(12/58)     [Aa 样式] [🔖 书签] [▶ 听书] ✕ │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│      正文区(虚拟滚动:仅渲染可视段 ± 10 屏缓冲)                          │
│                                                                      │
│      ……前文……                                                         │
│   ▸ 我要如何歌颂你,如何拥抱你。(← 当前朗读段:高亮 + 左侧呼吸进度点)        │
│      那些年我们错过的雨季,都落在了……(← 下一句:次要色预览)                 │
│      ……后文……                                                         │
│                                                                      │
├──────────────────────────────────────────────────────────────────────┤
│ 语音模式底部控制条(纯阅读模式折叠为一条细进度线):                         │
│ [⏮ 段-] [ ⏸ ] [段+ ⏭] ───●──────────  12:34 / 58:20                  │
│ 引擎 edge-tts ▾ · 音色 晓晓 ▾ · 语速 1.0x ▾ · [歌词: 桌面● 状态栏●]     │
└──────────────────────────────────────────────────────────────────────┘

[Aa 样式] 弹出面板:
┌──────────────────────────┐
│ 字体   [系统默认      ▾] │
│ 字号   [−] 18 [+]        │
│ 行距   [1.8]  字距 [0]   │
│ 边距   [标准 ▾]          │
│ 背景   (○白)(●羊皮)(○护眼绿)(○暗黑)(○自定义色) ← 阅读主题,独立于界面深浅色 │
│ [x] 自动翻页 速度 ──●──  │
│ [x] 跟随朗读滚动          │
└──────────────────────────┘   ← 所有项即时热更(CSS 变量)
```

**交互要点**

- **双向驱动**:播放进度 → 高亮 + 平滑滚动居中;反向定位(快进/快退):
  - **双击任意段落** → 从双击处开始同步播放(双击越靠后越快进,越靠前越快退)
  - **右键段落** → 上下文菜单,首选「从此处播放」:
      ┌────────────────────┐
      │ ▶ 从此处播放           │
      │ 🔖 在此处添加书签      │
      │ 📋 复制段落文本        │
      └────────────────────┘
  (单击仅选中文本,不触发播放,避免误触)
- 纯阅读:滚到底自动下一章(可关);语音模式:语音驱动翻页,滚动禁用手动自动翻页避免打架
- 目录侧栏:章节树 + 阅读进度百分比;书签按钮 → 本书书签列表(跳转/删除)
- 「听书」开关即进入/退出语音模式,退出时语音停止但进度保留

## 7. 业务流程 · 导入解析

```
[+ 导入 ▾] ─┬─ 本地文件 → 文件选择器(txt/md/epub,可多选)
            │     ▼ 读 Buffer → chardet 编码探测(UTF-8 BOM/GBK/GB18030/BIG5)→ 解码
            │     ▼ 章节识别
            │        txt : 「第X章/卷/回」「Chapter n」正则(导入向导可调整规则)
            │              └ 识别不到 → 整本单章 + 每 ~2000 字软分节
            │        md  : 按 # / ## 标题切章
            │        epub: 解 zip → 读 opf spine → 抽 xhtml 纯文本
            │
            └─ 网页链接 → 粘贴 URL
                  ▼ 主进程 fetch(跟随重定向 / UA / 10s 超时,只当网络代理规避 CORS)
                  ▼ 渲染层 DOMParser + @mozilla/readability 抽标题+正文(记 sourceUrl)
                  ▼ 失败(403/验证码)→ 明确报错提示
                  ▼ 单章成书,段落软分节
   两路汇合 ↓
   ▼ 清洗(多余空行/广告行)→ 段落数组 → 分段预演(不立即合成)
   ▼ 副本写入 OPFS: library/<id>.<ext>;元数据写 books.json(主进程)
   ▼ 首章解析缓存写 OPFS: chapters/<bookId>/<idx>.json
   ▼ 书架出现新卡片(封面色自动分配 + 标题)

重新抓取(仅网页书): 书架右键 → 拉最新内容覆盖正文,阅读进度保留
```

## 8. 业务流程 · TTS 合成-播放流水线(核心时序)

```
 主窗渲染层                Main(TTS 调度器)           引擎/网络            OPFS 缓存
    │ play(segIdx=12)          │                        │                   │
    │────tts:control──────────>│                        │                   │
    │                          │ 确保队列 [12..15] 就绪   │                   │
    │                          │──查缓存索引(idb)──────────────────────────>│ 命中?
    │                          │   未命中的段 ──synthesize(text)──────────>│
    │                          │<────────audio buffer + duration─────────│
    │                          │ 写入 opfs:tts/<hash> + idb 索引            │
    │<──audio-ready(12,b64)────│  (缓存命中的段立即回,零延迟)                │
    │ audio.play()              │                        │                   │
    │   timeupdate(~250ms)      │                        │                   │
    │────lyric:tick────────────>│ 节流汇聚                  │                   │
    │                          │──广播 tick─────────────────────────────────> 歌词窗/托盘/面板
    │   段12 ended → 段13 已就绪? │                        │                   │
    │────续播 13(无缝)─────────>│                        │                   │
    ▼                          ▼                        ▼                   ▼

 预合成(prefetch=3):播放第 N 段时后台合成 N+1..N+3,
 掩盖网络延迟 → 云端 TTS 听感连续;合成失败 → 重试1次 → 暂停+提示(可一键切引擎续播)
```

## 9. 业务流程 · 进度同步与歌词广播

```
进度源头(唯一): 主窗 <audio> timeupdate
   │  { bookId, chapterIdx, segIdx, segOffsetRatio, lineText, nextLineText }
   ▼
IPC lyric:tick → main 节流(≥200ms 间隔)
   ├→ 歌词窗: 上句淡出/当前句渐变切换(仅句边界重绘,轻量)
   ├→ mac Tray ticker: 当前句滚动截字
   └→ 托盘面板: 两行歌词 + 播放按钮状态

反向控制:
   歌词窗/托盘面板 [⏮⏸⏭] / 快捷键 → IPC tts:control → main → 主窗播放器执行
   → 执行结果经下一次 tick 自然广播(单一数据流,无回环)
```

## 11. 业务流程 · 纠错双通道

```
原始段落文本
   ├─ 显示通道(开关,默认关): 应用规则 → 阅读器渲染(改正显示)
   └─ 合成通道(常开): 规则替换 → 送 TTS 引擎(只改读法,不改显示)

规则示例(轻微级别 = 词级替换,不做 AI 校对):
   「帐号」→「账号」        scope:全局   显示+合成   ← 错别字
   「CEO」→「C.E.O」       scope:全局   仅合成     ← 改善读法
   「2024年」→「二零二四年」  scope:全局   仅合成     ← 年份读法
   自定义正则              scope:book:A 仅合成     ← 本书专有名词

规则管理页:
┌ 纠错规则 ────────────────────────────────────────┐
│ [+ 新增规则]  筛选[全部书籍▾]  [预览效果]              │
│ ┌──────────────────────────────────────────────┐│
│ │ 「帐号」→「账号」  [纯文本▾] [全局▾] [✓启用] [编辑][删] ││
│ │ 「CEO」→「C.E.O」 [纯文本▾] [全局▾] [✓启用] [编辑][删] ││
│ └──────────────────────────────────────────────┘│
│ 预览: 输入样例 → 并排显示 [原始文本 | 显示结果 | 合成结果]  │
└──────────────────────────────────────────────────┘

缓存联动: 规则增删改 → correctionVersion+1 → md5 key 变化 → 受影响段落自动重合成
```

## 12. 业务流程 · 提醒调度(默认开启)

```
主进程每秒心跳:
   active = 应用前台 且 (阅读器已打开 或 播放中)
   (最小化 / 播放暂停 / 系统休眠 → 计时挂起,不做无意义提醒)

   activeSeconds++ 且 播放继续
   │
   ├─ 20-20-20: activeSeconds % (intervalMin×60) == 0
   │    → 主窗顶部滑入休息浮层(20s 倒计时,可 [跳过])
   │    │     ┌──────────────────────────────────┐
   │    │     │  👁 已连续用眼 20 分钟               │
   │    │     │  看看 20 英尺(约 6 米)外,休息 20 秒   │
   │    │     │        ⏱ 18s        [跳过]        │
   │    │     └──────────────────────────────────┘
   │    └─ 可选系统通知(开关);不打断播放,倒计时结束自动收起
   │
   └─ 整点提示: 本地时间跨整点(分钟==0 且未提示过该小时)
        → 右下角轻 toast「现在是 15:00」+ chime 提示音(音量可调)
        → 不弹窗、不打断播放,2.5s 自动消失

配置: reminder.eye {enabled: true, intervalMin: 20, restSec: 20}
      reminder.chime {enabled: true, volume: 0.5}
```

## 13. 存储分层与配置导入/导出

```
┌ 存储分层 ─────────────────────────────────────────────────────┐
│ 渲染层                                                          │
│  localStorage : 仅小数据(UI 偏好 / 最近打开 / 窗口状态)             │
│  IndexedDB    : 结构化索引 —— 章节缓存索引、TTS 缓存索引(hash→文件、  │
│                  大小、lastUsed/LRU);与 OPFS 文件生命周期绑定        │
│  OPFS         : 大内容 —— library/<id>.<ext>(书籍副本)、            │
│                  chapters/<bookId>/<idx>.json(解析缓存)、           │
│                  tts/<hash>.<ext>(合成音频)                        │
│ 主进程 userData/data/*.json(原子写 + 30s 防抖 + 退出 flush)      │
│  books / bookmarks / corrections / settings / stats              │
│  (数据量小、需主进程调度或跨窗口共享的结构化数据)                     │
└────────────────────────────────────────────────────────────────┘

配置导出:
  设置 → [导出配置文件]
  → 勾选范围: [x] 全部设置  [x] 纠错规则  [ ] 书签
  → 生成 { app:"clear-sound", schema:1, exportedAt, settings, corrections, bookmarks }
    (apiKey 类字段默认脱敏留空)
  → 系统保存对话框 → clear-sound-config-YYYYMMDD.json

配置导入:
  设置 → [导入配置文件] → 选择 json
  → schema/版本校验(不合法 → 明确报错原因,不落盘)
  → 预览差异(列出将被覆盖的配置项)
  → 冲突策略: [覆盖] / [跳过冲突项]
  → 含 apiKey 的内容 → 二次确认才写入
  → 应用后即时生效: 样式热更;纠错规则变更 → correctionVersion+1 → 受影响段落重合成
```

## 14. 数据落盘结构

```
userData/
├─ data/                        # 主进程 JSON(原子写)
│  ├─ books.json  bookmarks.json  corrections.json
│  ├─ settings.json  stats.json
├─ library/ 章节缓存/ 合成缓存/    # 物理由渲染层 OPFS 管理
│                                 # (Chromium profile 内部,主进程不经手、不手写)
└─ cache/tts/ → 已由 OPFS 方案取代,不再使用该目录
```

> 注:OPFS 由渲染层 `navigator.storage.getDirectory()` 统一封装(`src/utils/vfs.js`),
> 主进程不直接读写;删除书籍时渲染层删 OPFS 文件 + IDB 索引,主进程删 books.json 记录,两侧事务式清理。
