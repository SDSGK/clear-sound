# 清声书坊 clear-sound

> 跨平台「边读边听」TTS 阅读器 —— 本地书库 + 阅读器 + 语音听书 + 状态栏/桌面歌词

把本地的 txt / md / epub / 网页文章变成有声书：导入即解析章节，朗读跟随高亮，
macOS 状态栏常驻歌词与播放控制，支持本地系统语音（零网络零 Key）与云端大模型语音。

## ✨ 功能特性

### 📚 书库与导入

- txt / md / epub / 网页 URL 导入，自动识别编码（UTF-8 / GBK / GB18030 / BIG5）
- 章节管理与批量导入：智能识别章题、重名分屏对比（覆盖/跳过）、单章软切分
- 大文件性能：流式导入、按章加载、虚拟滚动、TTS 分段惰性生成 + 缓存

### 📖 阅读器

- 阅读样式自定义：字体、字号、行距、字距、页边距、背景主题（白/羊皮纸/护眼绿/暗黑/自定义）
- 语音进度跟随：当前句高亮 + 自动滚动居中；点击任意段落从该处开播
- 自动翻页（纯阅读模式按速度滚动 / 听书模式跟随语音）
- 书签（任意段落位置，列表跳转）、阅读进度记忆、目录分组折叠（带动画）
- 纠错规则：错别字/多音字词级替换，纯文本/正则，全局或单书生效，显示与合成双通道独立开关
- 夜间模式（跟随系统/浅色/深色）、中英双语界面

### 🎧 语音听书

- 多引擎：macOS `say`（默认，零网络零 Key）/ Windows SAPI / Edge TTS（免费在线）/
  OpenAI 兼容接口（SiliconFlow / Groq / 自建网关，填 baseURL + Key 即用）
- 句级分段预合成 + 音频缓存：二次播放零成本、断点续听
- 无缝续播（gapless 双缓冲）、朗读文本清洗（引号/书名号/装饰符号不再读出）
- 音色按语言自动匹配、语速/音调/音量可调、合成通道纠错

### 🎵 状态栏与桌面歌词（macOS）

- 状态栏恒宽歌词 ticker：长文本跑马灯滚动、短文本整段静态展示，宽度不随内容跳动
- 菜单栏控制按钮组：⏮ 上一章 / ⏯ 播放暂停（随状态切换）/ ⏭ 下一章 / ♡ 加书签
- 点击歌词弹出托盘面板：双行歌词 + 控制 + 桌面歌词开关 + 引擎/音色/语速
- 桌面歌词：透明置顶无边框、可拖动/锁定、单双行、字体/渐变/描边/背景可调

### 📊 其他

- 使用统计：听书时长、阅读时长、合成字符数、连续使用天数，日/周/月视图
- 20-20-20 护眼提示、整点提示（默认开启，可配置）
- 配置导出/导入：设置/纠错规则/书签一键迁移，引擎 Key 自动脱敏
- 调试日志：操作记录 + 控制台报错统一落盘（本地时间戳），设置页一键复制

## 🧰 技术栈

Electron 35 · Vue 3 · Pinia · Element Plus · Vite · vue-i18n · TailwindCSS

## 🚀 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发模式(三窗口)
npm run lint       # 代码检查
npm run build:mac  # 打包 macOS
npm run build:win  # 打包 Windows
npm run build:linux# 打包 Linux
```

> macOS 状态栏歌词与控制按钮为 mac 专属；Windows 以桌面歌词为主。

## 📂 项目结构

```
electron/            主进程:窗口管理、书库 IPC、解析器、TTS 引擎与流水线、
                     状态栏 Tray、托盘面板、统计、提醒、纠错、书签、配置迁移
src/                 渲染层:书架/阅读器/统计/设置四个视图 + 歌词窗 + 托盘面板
  ├─ components/     章节面板、对比弹窗、纠错规则、播放条等
  ├─ stores/         Pinia:书库、播放器、书签、纠错
  └─ utils/          分段、缓存(OPFS)、朗读清洗、书名清洗、格式化等
docs/                PLAN.md 产品方案(需求分级/技术方案/里程碑/决策记录)
                     DESIGN.md 界面设计规范
```
